# ThesisLens · 知衡

**融合证据链与反向验证的买方投研智能体**  
以证据立论，以反证校准。

知衡面向大学生金融人工智能竞赛第六赛道“买方投资备忘录编制”。系统把公司披露、行业政策与行情资料组织为可追溯的研究证据，通过可复核的财务计算、大模型写作和第二轮反向核验，形成包含投资论据、风险、论据失效条件及跟踪指标的备忘录草稿。

当前为可运行的 **V0.1 初版**。以美的集团为主案例，格力电器、海尔智家为同行对照；公开资料截止 **2026年10月6日**。

## 快速运行

需要Python 3.10或以上，且包含SQLite FTS5。应用使用Python标准库和浏览器原生功能，无需安装额外依赖。

1. 克隆或下载本仓库，保留`知衡初版`与`知衡数据资料`两个文件夹的相对位置。
2. Windows双击`知衡初版/启动知衡.cmd`。其他系统运行：

   ```bash
   python3 知衡初版/launch.py
   ```

3. 浏览器会打开本机工作台，默认地址为`http://127.0.0.1:8765`。第一次启动自动建立本地检索索引。
4. 先选“资料模式”体验检索、财务计算和结构化草稿，再在“模型设置”配置自己的服务，切换“大模型分析”。

资料模式无需模型密钥。大模型模式默认读取环境变量`DEEPSEEK_API_KEY`，使用DeepSeek服务；可在设置中改为阿里云百炼等兼容接口，并填写对应的地址和模型名。初版已完成DeepSeek真实联调，其他供应商需自行验证兼容性。临时密钥只保留在服务进程内存中。

## 已实现

- **证据检索**：中文关键词、公司、期间和披露日期过滤；PDF物理页码与网页段落可回看。
- **财务核对**：三家公司2025年报和2026年半年报，营业收入、归母净利润、扣非净利润与经营现金流；保留原始单位、同比基期和重算公式。
- **同行比较**：财务表、同比图和最近260条交易日的未复权收盘价。
- **模型研究**：基于选取的公开证据生成投资备忘录，再用第二轮提示词检查数字、推断和证据缺口。
- **反向验证**：展示风险、论据失效条件、跟踪指标及待核实问题。
- **过程留存**：研究问题、证据、公式、模型输入输出和用量保存在本机；可导出Markdown备忘录及完整JSON记录。

资料说明见[资料包README](知衡数据资料/家电行业_截至2026-10-06/README.md)，详细目录见[资料目录](知衡数据资料/家电行业_截至2026-10-06/00_来源与索引/资料目录.md)。原始公告、财报及网页内容的权利归各自发布方，引用时保留出处。

## 检查与说明

在仓库根目录运行9项自动检查：

```bash
python -m unittest discover -s 知衡初版 -p "test_prototype.py" -v
```

应用启动后，可执行HTTP、引用原件与导出检查：

```bash
python 知衡初版/check_http.py
```

完整操作、模型接口说明和当前边界见[初版使用说明](知衡初版/README.md)。[初版验收记录](知衡初版/验收记录.json)记录了原型制作时的验证；每台电脑的索引与研究记录会在首次运行时自行生成，仓库不包含本机的密钥、研究数据库或导出历史。

当前检索使用关键词索引；核心财务指标仅覆盖六份已登记报告。模型复核使用同一模型服务，仍需人工判断引用是否充分支持结论。估值、目标价、自动新闻更新和语义重排尚未实现。
