# 知衡 · 买方投研工作台 V0.1

初版已经接入此前收集的家电行业资料，并用真实 DeepSeek 模型完成了“检索证据—财务计算—备忘录写作—反向复核”的联调。它用于第六赛道的原型演示，研究对象是美的集团、格力电器和海尔智家。

## 打开使用

在文件夹中双击 **启动知衡.cmd**。启动程序会找到本机 Python、启动仅监听本机的服务，并在页面准备好后打开浏览器。

默认地址：<http://127.0.0.1:8765>。如果端口已有其他应用使用，启动程序会选择8766—8784中的空闲端口。

首次启动会建立本地检索索引，当前索引已生成：96个来源、7,855个片段。Python需要3.10或以上版本，并支持SQLite FTS5；在当前电脑已确认可用。应用本身只使用Python标准库和浏览器原生功能，不需要安装前端依赖。

## 先体验这条流程

1. 在“研究工作台”选择美的集团，研究截止日保留2026-10-06。
2. 输入“美的集团2026年上半年营收、利润与现金流表现如何？有哪些需要反向验证的风险？”
3. 选择“大模型分析”，点击“生成备忘录”。若暂时没有模型密钥，可以使用“资料模式”。
4. 点击备忘录中的E编号，回看原文片段、来源日期及PDF物理页码。
5. 点击财务卡片的“查看公式”，核对原始单位、亿元换算和同比基期。
6. 在“财务与行情”对比三家公司。切换2025年度和2026年上半年，查看各自的原件。
7. 导出备忘录或完整记录，再到“运行记录”恢复同一次研究。

演示时优先突出：美的2026年上半年归母利润与扣非利润变化方向不同，系统会把这种差异带入风险与待核验问题，并保留证据。这是值得研究的线索，不能直接推导投资评级。

## 已实现功能

- 全量资料检索：中文双字索引、常用指标别名、公司/期间/披露日期过滤；PDF按页切分，网页保留段落位置。
- 证据链：每次研究单独编号；原文、公司、披露日期、页码、下载源可回看；OCR与日期差异明确标记。
- 财务事实：三家公司2025年报和2026年半年报，营收、归母净利润、扣非净利润、经营现金流四项指标；保留原值、原始单位和同比基期。
- 确定性计算：用Decimal进行金额换算与同比复算；海尔2025年报采用调整后基期；展示计算公式。
- 同行对比与行情：同比图、财务表与最近260条交易日未复权收盘价。
- 模型流程：第一轮基于选取的证据写作，第二轮使用独立提示词检查数字、单位、推测和资料缺口。
- 备忘录结构：摘要、投资论据、风险、失效条件、跟踪指标、待核实问题、复核记录、证据目录。
- 可重现记录：保存研究问题、研究时点、证据原文、计算、模型提示词与输出、模型名称、用量、数据索引哈希；不保存模型密钥。
- 导出：Markdown备忘录和包含完整过程的JSON，导出文件保存在`exports`文件夹。

## 模型配置

当前默认使用DeepSeek的`deepseek-flash`，读取本机环境变量`DEEPSEEK_API_KEY`。也可以在“模型设置”填写兼容服务地址、模型名和临时密钥。

模型密钥只保留在服务进程内存中，不返回浏览器，不写入运行记录或导出文件。设置中的临时密钥和服务选择只在本次服务运行期间有效。复制项目给其他电脑时，需要在该电脑配置自己的模型服务。

只有选择“大模型分析”并点击生成时，才会向所选模型服务发送研究问题、选取的公开证据片段和财务计算包。资料模式的检索、计算和草稿在本机完成，且明确标注未调用模型。

接口格式参考[OpenAI官方Chat Completions文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)；DeepSeek服务地址和模型参数参考[DeepSeek官方文档](https://api-docs.deepseek.com/)。实际联调使用DeepSeek，未测试其他供应商或所有兼容接口。

## 文件与运行记录

- `core.py`：语料索引、日期过滤、资料检索、财务计算和运行记录。
- `metrics.json`：六份财报的已登记指标、原始金额、单位、基期、出处和页码。
- `model.py`：兼容接口调用与进程内模型设置。
- `research.py`：证据选择、草稿生成、复核、引用检查和导出结构。
- `server.py`：仅监听127.0.0.1的本地应用服务。
- `static`：页面、样式与交互。
- `data/index.sqlite3`：生成的检索索引；可通过运行`core.py`重建。
- `data/runs.sqlite3`：已保存的研究记录；与索引分开，重建索引不会删除研究记录。
- `exports`：已导出的备忘录与过程文件。
- `test_prototype.py`：金额单位、同比基期、研究时点、中文检索、引用、期间、最新行业数据和模型流程的自动检查。

把初版交给队友时，应保留当前目录与旁边的`知衡数据资料`目录的相对位置。不要单独移动初版，否则找不到原始资料；如需修改资料位置，可以设置`ZHIHENG_DATASET`。

## 当前边界

这是一版可运行的投研原型。检索采用关键词索引，尚未加入向量召回与语义重排；核心财务指标目前只登记上述六份财报，不能把其他期间的文字检索结果当作已经完成的财务指标提取。

模型复核是第二轮提示词检查，使用同一模型服务，并非独立专家审计。程序检查引用编号、时点和已登记计算；引用是否充分支持结论、额外文字中数字的表头归属仍需人工回看原件。模型写作可能产生不充分的推断，复核事项会和正文一起展示。

尚未建立股本、TTM盈利、可比估值、DCF或情景估值，因此不输出目标价或买卖评级；尚未接入自动新闻更新、外部网络搜索或交易功能。本批研究资料截止2026年10月6日。
