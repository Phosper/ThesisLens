# 知衡计划书：Typora导出说明

`项目计划书_Typora.md`与现有V0.5计划书正文一致，仅把自定义分隔注释改为Typora支持的手动分页HTML。

1. 使用Typora打开`项目计划书_Typora.md`，选择浅色主题；不依赖程序生成PDF的排版工具。
2. 建议A4、正文11–12pt、页边距约20–25mm、行距1.5左右；这些是排版建议，不是比赛硬性规定。
3. 检查封面署名、七个章节、案例、验证状态和第三方说明引用；在文件菜单导出PDF。
4. 导出后逐页检查分页、标题孤行、乱码、链接、图片和最后一行是否被截断。不同主题/字体可能让章节跨两页；公开通知未规定8页，不必强行压页。

官方公开通知目前未附固定计划书模板，仅明确初赛提交PDF计划书与MP4视频。若登录后的提交平台另提供模板、页数或命名规定，应优先按平台要求调整。

本文仍是提交前草稿。此前真实模型复测eb64已完成；本次T2/T3逻辑补强仅离线验证并单列开发派生示例，尚未新增真实模型研究。金融论据与PE依据复审、视频及现场复现仍待完成，正文不得改成“已完成全部验收”。
