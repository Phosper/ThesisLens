项目名称：**知衡——融合证据链与反向验证的买方投研智能体**。

封面团队名称、学校、成员与指导教师暂留“待填写”，收到身份信息后统一更新。当前文件是可运行原型的完整参赛材料草稿，尚未向主办方提交。

- [项目简介MP4](知衡_项目简介.mp4)：3分30秒、H.264、1280×800、24帧/秒；真实界面截图编排并加字幕，无配音，明确标注历史模型保存记录及非实时连续录屏。

演示画面由浏览器实际操作采集，没有替换业务数字或抹去复核问题。字幕讲述产品能力和已核验的流程，视频展示保存记录，并非现场连续运行证明。口头讲解可依手册重新录制，身份信息需由团队提供。

## 另一台电脑复现

保留仓库中文目录的相对位置；Python 3.10以上且支持SQLite FTS5。双击`知衡初版/启动知衡.cmd`，或运行`python 知衡初版/launch.py`。基本检索与资料模式无需模型密钥。

PDF导入及历史示范恢复需先安装`知衡初版/requirements-optional.txt`。随后运行`python 知衡初版/demo_case.py --restore`，在“运行记录”打开“历史大模型示范 · 保存记录”。它会保留原运行编号、时间、估值、工具和模型输出，恢复时不请求模型。自己的研究需在“模型设置”配置并测试自己的服务。

## 提交前

1. 补齐封面身份信息；不能把“待填写”版本直接作为最终提交。
2. 金融同学或指导教师复审数字归属、论据支持关系、情景假设和20题标注，保留签认依据。
3. 在另一台电脑验证启动、模型账号、研究生成、原件与导出；真实生成会产生模型调用费用。
4. 核对主办方最新命名与提交规定。已提供的比赛通知要求PDF计划书和不超过5分钟、500MB的MP4；以主办方最新通知为准。

系统当前支持第六赛道核心研究闭环。向量召回、自动OCR、无人值守推送、更广财务解剖自动登记与独立盲测是后续增强，不列为已完成能力。
