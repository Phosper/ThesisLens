## 另一台电脑复现

保留仓库中文目录的相对位置；需要Python 3.10以上与SQLite FTS5。双击`知衡初版/启动知衡.cmd`，或运行`python 知衡初版/launch.py`。基本检索与资料模式无需模型密钥。

PDF导入及历史示范恢复先安装`知衡初版/requirements-optional.txt`。运行`python 知衡初版/demo_case.py --restore`默认恢复本次V0.5保存记录；`--version v04`可显式查看旧版示范。恢复不请求模型，保留原编号、时间、初稿/修订输出、原复核及生成时判断；最新有限规则的补充意见与开发复查边界另行展示。自己的研究应在模型设置配置并测试自己的服务。

开发侧逻辑修订示例需显式加`--version v05_logic`恢复；父记录是eb64fcc72e43，但修订内容由开发者整理，不是该次模型原文。它保留独立标识、改动说明和待核验状态；历史复核不能作为派生文本已通过的证明。
