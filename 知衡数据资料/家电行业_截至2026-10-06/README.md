# 知衡：买方投研智能体首批资料包

这批资料以美的集团（000333）为主案例，以格力电器（000651）和海尔智家（600690）作同行对照。统一研究截止日为2026年10月6日，适用于第六赛道“买方投资备忘录编制”的原型与演示。

## 已收集内容

- 公司原始PDF：69份，其中完整定期财报51份，审计、内控、经营公告及投资者问答18份。
- 三家公司各有2021—2025年年报、2022—2026年半年报、2023—2026年一季报、2023—2025年三季报。
- 行业与政策网页：23项，另有1份政策PDF全文。涵盖国家统计局消费与工业数据、工信部家电生产数据、以旧换新政策及拨款进展。
- A股行情：3家公司各1023条未复权日线，共3069条，覆盖2022年7月15日至2026年9月30日。
- PDF总页数：7,425页；提取文字约737.1万字符。原生文字少的页面已尝试中文OCR，31页采用OCR补充。
- 共96个已落地的来源条目。不同PDF可能包含相同财务章节；这个数量不代表独立投资观点数量。

## 从哪里开始

先看[起步材料清单](<起步材料清单.md>)，再打开[完整资料目录](<00_来源与索引/资料目录.md>)。目录里的每一项都有本地原件和下载源。

搭建知识库时，先用`05_可检索文本/逐页语料.jsonl`与`网页语料.jsonl`，从6份最新财报开始。每条PDF记录保留来源编号、公司、期间、发布日期和物理页码。按问题检索相关页后，再让模型给出结论和引用。不要把全部财报一次性塞进提示词。

## 文件说明

- `00_来源与索引`：人可读目录、公司/行业/行情索引、总索引、质量检查、公开查询记录。
- `01_公司财报`：三家公司的年报、半年报、一季报和三季报原始PDF。
- `02_审计与内控`：已成功下载的美的、格力审计与内控资料。
- `03_经营公告与调研`：关联交易、回购、分红、减持、风险提示与美的投资者关系问答。
- `04_行业数据与政策`：网页原件、正文文本、26张去重后的原始表格及政策附件。
- `05_可检索文本`：每份PDF文本、逐页语料、网页语料、OCR补充结果与字段说明。
- `06_市场行情`：原始接口响应和包含日期、开高低收、成交量的日线JSON。

## 使用前需要知道的口径

原件保持下载时的内容。正文和OCR是辅助检索材料，引用财务数字、审计意见和政策条款时，应回看原件。OCR页明确标有`text_origin`与`ocr_human_verified=false`；目前仍有25页文字较少，可能是图片、图表、签字页或空白页，不能据此判断没有风险。

这批资料尚未制作统一的财务指标表。金额单位、合并/母公司口径、报告期间、同比基期、重述或修订版本都需要核验。第一步可以提取营收、归母净利润、经营现金流、毛利率、存货、应收账款和分红，再进行跨年、同行比较。

行情是未复权价格，未与第二行情源交叉核验。不能直接用它计算含分红的长期总收益；成交量单位保留接口口径。市盈率、市净率、TTM盈利、总股本和估值情景尚未计算，不能把日线价格当成已完成的估值。

主资料以法定披露与政府数据为主；部分历史财报通过新浪财经公开转载取得，目录明确标注。公司新闻和投资者问答属于公司表述，需要与财报交叉核对。来源可公开访问不等于获得任意再分发授权，展示与提交时保留出处。

海尔另外10份独立审计、内控和附属评估报告的下载受到访问验证限制，只有公开条目，未计入已收集文件。海尔年报中的相关审计章节仍可检索；缺失清单见完整目录。

商务部一项政策解读网页的正文显示日期和元数据日期存在差异，索引保留了两者，并按较晚的元数据日期记录可用时间，均早于本批截止日。

## 本批验收

已检查文件是否存在、原件哈希、PDF页数、编号唯一性、披露日期、公司与报告年份文字匹配，以及逐页语料条数。另抽看了三家公司代表性报告封面与审计扫描封面。检查记录见`00_来源与索引/质量检查.json`。

这是资料收集与检索准备，不是已经完成的投资结论、财务模型或投资建议。
